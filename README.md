## Project Overview

**Quazenthor (QWBQ)** is a fixed-supply BEP-20 token deployed on the BNB Smart Chain mainnet. It features a permanently capped total supply and a fully verified, immutable smart contract. Token distribution is performed manually and is fully transparent on-chain. The contract contains no minting, burning, taxation, or upgradeability mechanisms.

> **Fixed-Supply BEP-20 Token on BNB Smart Chain Mainnet**  
> Total Supply: **5.00T QWBQ** · Owner: **toora dokht**
