## Project Overview

**Quazenthor (QWBQ)** is a fixed-supply BEP-20 token deployed on the BNB Smart Chain mainnet. It enables real blockchain interaction with standard BEP-20 functions including transfers, approvals, allowance validation, and event observation. Token distribution is performed manually and is fully transparent on-chain. The contract is immutable and contains no minting, burning, taxation, or upgradeability mechanisms.

This repository serves as the official public reference hub for project documentation, transparency disclosures, and technical verification resources.

**Fixed-Supply BEP-20 Token on BNB Smart Chain Mainnet. Total Supply: 5.00T QWBQ. Owner: toora dokht.**

The project prioritizes transparency, immutability, and public verifiability. All on-chain activity is fully visible on BscScan.

All project documentation, updates, and communications are managed by the founder or designated contributors under her coordination.

## Why This Token Exists

QWBQ was created to provide a transparent and immutable BEP-20 token on BNB Smart Chain mainnet with a permanently fixed supply and clear on-chain visibility.

The purpose is to allow practical observation of how a fixed-supply BEP-20 contract behaves in a live blockchain environment.
