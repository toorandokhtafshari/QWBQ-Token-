## Project Overview

**Quazenthor (QWBQ)** is a fixed-supply BEP-20 token deployed on the BNB Smart Chain mainnet.  
It features a permanently capped total supply and a fully verified, immutable smart contract.  

Token distribution is performed manually and remains fully transparent on-chain.  
The contract contains **no** minting, burning, taxation, pause, blacklist, or upgradeability mechanisms.

**Why it exists:**  
To provide a transparent, immutable, and publicly verifiable BEP-20 reference token with clear on-chain visibility of every transfer and holder balance.
